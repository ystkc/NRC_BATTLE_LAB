# 实时对战对比

启动：

    python -m manual_input.server --host 127.0.0.1 --port 8766

访问本机的 8766 端口。修改后端或核心后需重启服务，前端更新后强制刷新页面。

## 主流程：输入 → 核心预测 → 实测对比

1. 录入起始阵容、最大 HP，通过 /start 1（我方先手）或 /start 2（对手先手）进入对战。开始前仍保存独立开场保存点。
2. 修改起始 HP、能量、技能、双方行动、增减益层数或天气后，页面防抖约 240 毫秒调用 /api/simulate。固定随机种子避免同一输入的随机结果不断变化。
3. 核心返回的 own/opponent.after、shared_after 快照被解释为精灵、HP 进度条、能量、技能数值、状态图标和天气，不是单纯展示 JSON。计算中的旧结果标记为等待，过期响应会被丢弃。
4. 在下方“核心预测 ↔ 实测对比”单独录入实际 HP、能量、状态、天气和 MP，显示一致或差值。实测区不会触发重算，也不会覆盖上方起始输入。
5. 当前预测完成后，可点击“提交对比并下一回合”。保存起始输入、核心预测和实测结果，仅明确录入的实测值带入下一回合，未录入值保持原输入，不自动采用预测值。需自行确认换人后的当前上场精灵等状态。

记录是辅助追溯功能，不是主操作入口。侧栏“历史保存点”可查看开场和已提交对比；刷新恢复保存点，未提交的修改不承诺刷新恢复。

## 状态栏

三列依次为我方、共享、对方。我方/对方列编辑当前上场精灵的状态，包含双方行动和 MP；中间列编辑天气、剩余回合及随机种子，默认无天气。

状态素材暂用内置 Font Awesome 免费 SVG：交叉剑代表攻击、盾代表防御、鞋印代表速度、闪烁星星代表连击加成。增益绿色、减益红色，右下角数字框编辑层数；中毒、燃烧、冻结、寄生、星陨和萌化也可输入。动态图标遵守减少动画偏好。来源及许可见 static/FONT-AWESOME-NOTICE.md，无运行时 CDN 依赖。

增减益通过 CreatureState.buffs/debuffs 传入核心；异常状态和连击加成通过 CreatureInput.metadata.status_stacks 映射到内核。未知特性、缺失六维或潜在分支仍在预测旁提示，含占位值的预测不代表确定结论。

## 快捷键与录入

- 任意位置按 / 打开命令弹窗，光标在末尾，不选中已有斜杠；/nc 可跳过未知对手阵容。
- 名称候选只显示基本型。悬浮头像查看立绘，Space 下一形态，Shift+Space 上一形态，循环切换。
- 未收录名称只在执行 /start 时统一提示；Enter 或 Space 确认，Esc 取消。
- 点击头像选择当前上场精灵；点击名称或按 o 录入我方当前精灵。HP、最大 HP 和能量输入在同一行。
- 对方技能只读。我方 k 开始编辑技能，不插入 k；Tab 补全并立即进入下一技能，Shift+Tab 上一个，第四技能后的 Tab 等效 Esc。
- 威力普通输入框位于技能右下角，系别在左下角，能耗左上角。↑↓ 在双下、单下、空心圆、单上、双上五档提示间切换；候选展开时则用于选择候选。效果提示只用于人工核对，不会强行覆盖核心系别规则。
- w 聚焦天气输入，支持名称、首字母和拼音候选补全。
- n 开始我方行动，输入框显示 n；m 开始对方行动。随后 k+1～4 选择技能，s+1～6 切换，e 聚能，p 道具/等待。
- 一秒内连续按两次 Enter 仍可提交并下一回合，但第一次不再弹出倒计时提示。计算未完成或失败时不能提交旧预测。
- Esc 取消聚焦并恢复默认提示；小屏左侧按钮展开保存点侧栏，遮罩或 Esc 关闭。

## 数据与验证

真实计算需要完整的 data/nrc_wiki.db（包含 spirit_forms、skill_catalog 等表）。目录不可用时接口返回明确错误，不伪造候选或结果；恢复数据后重启服务。保存文件位于 data/manual_battles。

安装项目 dev 依赖后运行：python -m pytest tests/test_manual_input.py -q。回归测试使用隔离输入运行真实核心，并用本机 Chrome 无头模式检查桌面和小屏交互、五档图形、天气补全、请求过期处理、实测隔离及回合提交。无 Chrome 时跳过浏览器测试。

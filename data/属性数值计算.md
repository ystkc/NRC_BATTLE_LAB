
# 性格机制和种族值详解

数值最终计算公式是：四舍五入((四舍五入(零级基本属性+等级×每级加值))×性格加成+成长值)

# 性格加成

性格 生命+ 物攻+ 魔攻+ 物防+ 魔防+ 速度+

生命- / 逞强 理性 坦率 焦虑 热情

物攻- 沉默 / 聪明 稳重 警惕 胆小

魔攻- 平和 固执 / 天真 害羞 开朗

物防- 忧郁 大胆 专注 / 温顺 急躁

魔防- 粗心 调皮 偏执 懒散 / 莽撞

速度- 踏实 勇敢 冷静 悠闲 慎重 /

特别的对PvP而言，其中+都是+20%，-都是-10%，/表示不存在这种性格

各种资质代表此精灵对应项提升的难易程度，也就是每升一级该能力提升的多少

# 成长值

PvP固定成长值为5星，也就是5次升星和50次成长，也就是生命成长值100，其余成长值50。5次升星则更为复杂，涉及资质值计算。

资质值是初始随机，但是可修改、可提升的属性，每个精灵最多拥有三项大于零的资质值，其余为0

其中PvP固定5升星的意思就是资质值为基础成长值的6倍，例如随机精灵基础资质值为+8，那么最终资质值就是+40，资质值一般为5-10，但是低于8的一般不会用来PvP，因为提升并不昂贵

# 等级加值

5维度等级加值计算公式是种族值*0.01+资质值*0.005，5维度指除了生命之外的维度，注意每个维度的种族值和资质值都可能不同的

生命维度等级加值要在5维度的基础上乘2再加1

# 零级基本属性

零级基本属性计算公式是10+(5维度等级加值*50)，该基本属性公式适用于6维度，生命维度也采用【*2+1之前】的数值计算。

# 总结

综上，我们可以得到PvP环境下的数值计算公式：

生命=四舍五入(四舍五入[1.7×种族值+个体值×0.85+70]×（1+性格修正）)+100
其他=四舍五入(四舍五入[1.1×种族值+个体值×0.55+10]×（1+性格修正）)+50
为了在极端边界条件下（例如种族值105，个体值0，无性格修正）保持和游戏内计算结果一致，需要严格使用Float32类型

也就是说有两个变量，一个是资质，另一个是性格，只能通过观察得出。

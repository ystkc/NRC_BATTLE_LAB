# NRC Battle Lab

- `nrc_core/`：战斗规则、状态模型、效果引擎与训练适配器。
- `nrc_ai/`：搜索、自博弈、回放与训练。
- `nrc_platform/`：多回合对战平台。
- `collector/`：屏幕采集与数据解析。
- `manual_input/`：手动对战记录器。
- `ocr_service/`：Windows OCR 服务。
- `ocr_benchmark/`：OCR 实验工具。
- `data/`：规则与实验数据。
- `scripts/`：维护和实验入口。
- `tests/`：自动化测试。

详细说明见各目录内的 `README.md`。安装：`pip install -e .`。

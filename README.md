# NRC Battle Lab

洛克王国世界 PvP对战模拟器。

本项目由玩家独立维护，与魔方工作室、腾讯游戏等无关。游戏图片、音视频等素材归魔方工作室、腾讯游戏及相应权利人所有，不适用本项目的许可；项目代码采用Apache License 2.0。其他原创文字及整理成果（具体范围：`*.md,*.csv`）采用 CC BY-SA 4.0 协议，转载或使用请注明出处。

安装：安装Python ≥ 3.10，然后执行:
```
pip install -e ".[dev]"
```

启动：`python -m nrc_server.server --host 127.0.0.1 --port 8767`。使用两个浏览器访问127.0.0.1:8767，编辑阵容，一方创建对局，另一方加入对局即可。

安装 Google Chrome 并启动服务器后，运行 1007 对局回归用例。

```bash
python tests/1007/playwright_1007.py
```

脚本通过 Python Playwright 启动无界面的 Chrome，为双方创建独立会话，并将断言结果和战报快照写入 `tests/1007/1007-results.json`。服务器使用其他地址时，可设置环境变量 `NRC_TEST_URL`。

如需在 Windows 上观看对局，可通过 `python tests/launchBrowser.py` 打开两个 360 极速浏览器 X 窗口，再运行 `python tests/1007/playwright_1007.py --cdp`。可用 `python tests/tileWindows.py` 将窗口左右排列。

架构简介：

- nrc_core：全知规则计算，含数值计算、伤害计算、结果模拟。
- nrc_platform：对战管理模块，含对局状态、操作提交、对局历史与可见性管理。
- nrc_server：Web UI。含 HTTP 认证、路由、资源和原生 ES 模块页面。
- nrc_ai：MCTS研究代码，接口已过期，不可用。暂不维护，后期重写。
- wiki_crawler：Wiki 数据采集，采集精灵图片、技能特性图片及其描述。
- data：规则、人工补充规则、数据库与素材。
- ocr_service：屏幕识别，虽然实验综合性能最优，但生产测试性能不如RapidOCR，已废弃。
- docs/battle_audit: 由Agents主导的项目静态审查

# 阶段任务

1. 完善全知模拟核心

方法：使用常见的、双方属性数值完全知晓的队伍进行对战，与当前模拟结果进行对比，对明显错漏的进行修正。并积累一些初步数据（并不是实战级数据，但也是真实的游戏对战数据）

定期目标：每个赛季更新时，重新使用wiki_crawler读取新的精灵、wiki变动以及平衡性调整，并以此为依据更新模拟核心。

分支目标：写一个基于RapidOCR的对战视频文字自动提取。目前技能、血量、精灵名都可以通过定区域OCR完成，难点主要是伤害数字位置不定，且干扰多难以识别，暂时使用手动录入。

目标：常见队伍的对战不会出现明显机制错误。目前仅有一个测试案例。

2. 完善半全知模拟

方法：将其中一方改为未知，只提供一方的阵容信息，模拟真实用户PVP对战的情况，根据伤害数值推测对方的数值等。

目标：第一步积累的数据能正确推出另一方的信息。

3. 完善MCTS研究

方法：将已知方的输入输出数据结构化以便训练，进行大量自对局训练。

目标：训练完后，将随机出招的算法、只会选择克制技能的算法，以及有少量硬编码规则的算法作为baseline，与MCTS算法进行对战对比得到显著提升。

4. 收集真实对战案例

方法：使用该模型进行真实对战，取得真实的实战级数据，包括常见阵容、常见配招，建立经验指导的神经网络（类似棋谱），与MCTS进行结合训练。

目标：与baseline以及上一版的模型对战对比得到显著提升。

# T06 规则疑问

## T06-Q01 体重相关技能缺少威力定量映射

对象：以重制重、吨位压制、砂糖弹球，见对应SKILL稳定ID的object_review.csv。

依据：当前原文分别只说明敌体重越高、越低、双方体重差越大时威力越高；data/*.md、部分规则详解未给威力分档或公式。现实现仅DAMAGE，没有重量动态原语。

需要用户说明：三个技能各自精确威力分档/公式、体重的数据字段，以及变化后体重是否参与。即使能确认当前静态伤害遗漏动态机制，也不能猜出应实现的数量关系。

确认方式：指定相同攻防与不同体重的3组输入，给出游戏技能面板威力或伤害，核对分档边界和最大/最小值。

## T06-Q02 比值相关技能缺少威力公式

对象：闪击、鸣沙陷阱。

依据：原文仅说明自己速度/物防比敌方越高时威力越高，缺少公式与上限。当前仅DAMAGE。data/伤害数值计算.md定义通用伤害公式，没有定义这两个技能的动态威力。

需要用户说明：取基础或有效速度/物防、按差值还是比值计算、如何取整以及威力上下限。确认方式：相同比值但不同绝对数值、相同差值但不同比值的输入进行对照。

## T06-Q03 秋收的草系环境接口

依据：data/部分规则详解/秋收：草系环境.md只说明“目前还没有草系环境”且推测特殊天气；特性原文是草系环境下机械技能威力+50%。无法从该说明推出整个特性已被权威明确宣布未上线。

当前：配置空ON_TURN_START；草系环境在现有天气集合下不可达。结论规则存疑，可达性单列；不直接标未上线。

需要用户说明：本模拟器是否需要支持人工传入草系环境；若需要，应明确环境数据类型、作用范围、持续时间和何时判定。确认方式：显式注入草系环境后，机械/非机械两技能对照，离开环境后恢复。
